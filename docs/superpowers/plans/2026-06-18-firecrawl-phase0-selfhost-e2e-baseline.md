# Firecrawl Phase 0 — Self-Host Bring-Up + E2E Baseline (on Crabbox) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the core self-hosted Firecrawl stack up on the remote Crabbox box (`crabbox-runner`) and prove the scrape/crawl/map/search/extract pipeline green with a re-runnable smoke suite that becomes the regression gate for the later upstream merge (Phase 0.5).

**Architecture:** Onboard the inner `firecrawl/` repo to Crabbox (`crabbox init`), which rsyncs the working tree to the box and runs commands there. A `docker-compose.local.yml` override neutralizes the three Traefik/Cloudflare-Access edge services so only the core pipeline starts. Secrets are injected from self-hosted Infisical, never committed. A `scripts/smoke.sh` suite exercises the API end-to-end over `localhost:3002` on the box; scrape/crawl/map run unconditionally, search/extract are gated on their external dependencies (SearXNG / LLM key), matching the repo's own test-gating convention.

**Tech Stack:** Crabbox (remote box leasing + rsync), Docker + Docker Compose, the Firecrawl monorepo (`apps/api` harness, `apps/playwright-service-ts`, `apps/nuq-postgres`), Redis, RabbitMQ, Postgres, Infisical CLI, bash + curl + jq for the smoke suite.

## Global Constraints

- **Scope is Phase 0 ONLY.** No authentication changes (no Keycloak/OIDC/auth.md/ID-JAG, no removing `cf-access-verifier`) and no upstream merge — those are Phases 0.5–5. Source of truth: `docs/superpowers/specs/2026-06-18-firecrawl-selfhost-auth-redesign-design.md`.
- **Execution environment = Crabbox.** Everything that touches Docker/the stack runs on `crabbox-runner` via `crabbox run`, NOT on this local machine. Local machine only edits files + drives `crabbox`.
- **Inner repo path (the Crabbox repo):** `/home/theo/Documents/Theochinomona.tech/firecrawl/firecrawl` (this is where `crabbox init` runs and what gets synced).
- **Queue backend = Postgres.** Leave `NUQ_BACKEND` unset; do NOT enable the opt-in FoundationDB services. `nuq-postgres` is the queue.
- **`USE_DB_AUTHENTICATION=false`** (self-host default) — the API accepts any bearer token; the smoke uses `TEST_API_KEY` as a placeholder bearer.
- **Secrets via Infisical, never committed.** `.env` is gitignored; no secret value appears in any committed file, log, or this plan.
- **Git hygiene:** work on a feature branch in the inner repo (never commit to `main`); surface any pre-existing uncommitted changes instead of bundling them; do NOT modify the project's existing CI pipeline files (`.github/workflows/*` that predate this work). The `crabbox init`-generated `.github/workflows/crabbox.yml` is onboarding scaffolding and is reviewed before committing.
- **Inner-repo conventions:** the inner `firecrawl/CLAUDE.md` defines a ByteRover (`brv`) workflow and a `pnpm harness jest` testing convention. Phase 0 is infra/meta work (bring-up, smoke, commits), which `brv` itself says to skip; no `apps/api` source code is changed here, so the harness test convention does not apply to this plan.

```bash
#!/usr/bin/env bash
# Phase 0 E2E smoke for the self-hosted Firecrawl core pipeline.
# Runs ON the Crabbox box against the box-local API.
# Mandatory (no external deps): health, scrape, crawl, map.
# Gated: search (needs SEARXNG_ENDPOINT), extract (needs an LLM key).
# Usage (on the box, from the repo root):  bash scripts/smoke.sh
set -uo pipefail

BASE="${FIRECRAWL_BASE_URL:-http://localhost:3002}"
# self-host accepts any bearer (USE_DB_AUTHENTICATION=false); use TEST_API_KEY if set.
KEY="${TEST_API_KEY:-fc-smoke-test}"
AUTH=( -H "Authorization: Bearer ${KEY}" -H "Content-Type: application/json" )
TARGET="https://firecrawl.dev"
fail=0

pass() { echo "PASS  $1"; }
bad()  { echo "FAIL  $1"; fail=1; }
skip() { echo "SKIP  $1"; }

# --- health ----------------------------------------------------------------
code=$(curl -s -o /dev/null -w "%{http_code}" "${BASE}/")
[ "$code" = "200" ] && pass "health GET / -> 200" || bad "health GET / -> $code"

# --- scrape ----------------------------------------------------------------
resp=$(curl -s "${AUTH[@]}" -X POST "${BASE}/v2/scrape" -d "{\"url\":\"${TARGET}\"}")
ok=$(echo "$resp" | jq -r '.success // false')
mdlen=$(echo "$resp" | jq -r '(.data.markdown // "") | length')
if [ "$ok" = "true" ] && [ "${mdlen:-0}" -gt 0 ]; then pass "scrape (markdown ${mdlen} chars)"; else bad "scrape (success=$ok mdlen=$mdlen)"; fi

# --- map -------------------------------------------------------------------
resp=$(curl -s "${AUTH[@]}" -X POST "${BASE}/v2/map" -d "{\"url\":\"${TARGET}\"}")
ok=$(echo "$resp" | jq -r '.success // false')
n=$(echo "$resp" | jq -r '(.links // []) | length')
if [ "$ok" = "true" ] && [ "${n:-0}" -gt 0 ]; then pass "map (${n} links)"; else bad "map (success=$ok links=$n)"; fi

# --- crawl (submit -> poll) -----------------------------------------------
resp=$(curl -s "${AUTH[@]}" -X POST "${BASE}/v2/crawl" -d "{\"url\":\"${TARGET}\",\"limit\":5}")
id=$(echo "$resp" | jq -r '.id // empty')
if [ -z "$id" ]; then
  bad "crawl submit (no id; resp=$(echo "$resp" | head -c 200))"
else
  status=""; for i in $(seq 1 60); do
    s=$(curl -s "${AUTH[@]}" "${BASE}/v2/crawl/${id}")
    status=$(echo "$s" | jq -r '.status // empty')
    [ "$status" = "completed" ] && { done_n=$(echo "$s" | jq -r '(.completed // 0)'); pass "crawl ${id} completed (${done_n} pages)"; break; }
    [ "$status" = "failed" ] && { bad "crawl ${id} failed"; break; }
    sleep 5
  done
  [ "$status" = "completed" ] || [ "$status" = "failed" ] || bad "crawl ${id} timed out (last status=$status)"
fi

# --- search (gated on SEARXNG_ENDPOINT) -----------------------------------
if [ -n "${SEARXNG_ENDPOINT:-}" ]; then
  resp=$(curl -s "${AUTH[@]}" -X POST "${BASE}/v2/search" -d '{"query":"firecrawl"}')
  ok=$(echo "$resp" | jq -r '.success // false')
  [ "$ok" = "true" ] && pass "search" || bad "search (success=$ok)"
else
  skip "search (SEARXNG_ENDPOINT not set)"
fi

# --- extract (gated on an LLM key) ----------------------------------------
if [ -n "${OPENAI_API_KEY:-}${LLM_API_KEY:-}" ]; then
  resp=$(curl -s "${AUTH[@]}" -X POST "${BASE}/v2/extract" \
    -d "{\"urls\":[\"${TARGET}\"],\"prompt\":\"Return the company name.\"}")
  ok=$(echo "$resp" | jq -r '.success // false')
  [ "$ok" = "true" ] && pass "extract" || bad "extract (success=$ok)"
else
  skip "extract (no LLM key set)"
fi

echo "----"
if [ "$fail" = "0" ]; then echo "SMOKE GREEN"; exit 0; else echo "SMOKE RED"; exit 1; fi
```
Expected: file created. Make it executable: `chmod +x /home/theo/Documents/Theochinomona.tech/firecrawl/firecrawl/scripts/smoke.sh`.
